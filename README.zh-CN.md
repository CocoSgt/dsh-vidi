# dsh-vidi

[English](README.md) | 中文

DeepSeek Harness 里的视频工具：看直播、视频和播客，同时出任意语言的字幕，再让 DeepSeek 帮你截图、剪片段、下载、总结。

## 能做什么

- **打开任何来源**：YouTube、B 站等 yt-dlp 支持的网站，小宇宙节目，m3u8 / rtmp / srt 直播流，本地文件（直接拖进来），也可以用 OBS 推流过来。
- **自动出字幕**：视频一打开就开始，可以随时暂停、继续。单语、双语都行，主字幕和副字幕各选一种语言；网站自带的字幕也能直接显示，或者作为参考。
- **两种节奏**：实时模式边播边出；精修模式晚一点出，但会结合上下文把听错的词改对。
- **字幕模型会看画面**：精修时结合视频页面的标题、简介、评论，所选模型能看图时还会带上那一段的画面，顺便整理这期视频的词表（人名、术语）。
- **在视频旁边和 DeepSeek 对话**：截取此刻、剪下这段、总结要点、下载原片，都在同一个会话里完成，文件存在视频目录下。
- **导出**：SRT / VTT 字幕，逐句或按段落的文字稿，带字幕轨的片段。
- 中英文界面，手机上也能用。

## 安装

在 DSH 里打开 **插件 → 安装第三方插件**，填 `dsh-vidi`。装好后侧栏会出现 **视频** 按钮；在对话里贴视频链接，输入框上方也会出现「在视频里打开」。

需要 DSH 0.2.2 或更新的版本。

### 依赖

| 工具 | 用途 | 安装（macOS） |
|---|---|---|
| ffmpeg | 播放、录制、截图、剪辑 | `brew install ffmpeg` |
| yt-dlp | 打开网站视频 | `brew install yt-dlp` |
| whisper.cpp（可选） | 在本机转写 | `brew install whisper-cpp`，再下载模型 `ggml-large-v3-turbo-q5_0.bin` 到 `~/.dsh/live/models/` |

不装 whisper.cpp 也能用：在设置里把转写模型换成在线服务即可。

## 两个模型

设置（齿轮）里分开配置：

- **转写模型**：把语音转成文字。默认用本机 Whisper；也可以选 OpenAI、Google Gemini、Groq、硅基流动、智谱 GLM。
- **字幕模型**：精修、翻译、整理词表。默认 DeepSeek，列表里是你在 DSH 里配置的所有模型，能看图的会标出来。

在线转写直接用你在 DSH 模型设置里配好的服务商（OpenAI、Google、Groq、硅基流动、智谱 GLM），它们的密钥和地址拿来就用，不管密钥叫什么名字。DSH 里还没配的服务，也可以在视频页里直接填密钥，验证后存进 DSH。

## 用 OBS 推流

打开视频页，空白处会显示推流地址和串流密钥。OBS 里服务选「自定义」，填进去就行。默认端口 RTMP 1935、SRT 9000，可在插件设置里改。

## 数据放在哪

录像、字幕、截图、片段都在 `~/.dsh/live/jobs/<编号>/`，可在插件设置里改目录。

## 已知限制

- 小宇宙的视频节目在网页上只有 60 秒预览，完整视频要在 App 里登录才能看，所以按完整音频加封面播放。
- 需要登录才能看的网站视频，会借用浏览器里已登录的状态（设置 → 网站登录）。
